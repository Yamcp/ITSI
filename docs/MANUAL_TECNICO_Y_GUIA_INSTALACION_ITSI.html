Parte I — Manual técnico

1. Descripción general del sistema

ITSI es una aplicación web orientada al Departamento de Vinculación (o unidad equivalente) de una institución educativa. Permite gestionar prácticas preprofesionales, servicio comunitario, convenios con entidades receptoras, documentos asociados a cada modalidad, actividades de educación continua, evaluaciones, asistencias, instructores y docentes tutores, así como perfiles y cuentas de usuario. El acceso está segmentado por roles (coordinación, docente, estudiante), cada uno con rutas y controladores bajo prefijos coord, docente y estudiante.

La autenticación centraliza en AuthController; existen flujos de recuperación de contraseña por correo (configuración SMTP en app/Config/Email.php o variables .env).

2. Arquitectura del sistema

ITSI sigue el patrón MVC de CodeIgniter 4: el navegador envía peticiones HTTP al servidor web; el punto de entrada público es public/index.php, que delega en el enrutador. Los controladores orquestan la lógica, los modelos acceden a MySQL y las vistas (PHP + HTML + CSS/JS) generan la respuesta. Algunas funciones auxiliares residen en app/Services y app/Helpers.

Flujo de petición (resumen)

  1. El usuario accede a una URL bajo public/ (o virtual host apuntando a public).
  2. app/Config/Routes.php resuelve el controlador y método.
  3. Los controladores utilizan modelos (app/Models) y devuelven vistas (app/Views) o redirecciones.
  4. Los datos persistentes viven en la base itsi, definida en el script bddITSI.sql.

5. Configuración del entorno de desarrollo

  • Instale XAMPP (o stack equivalente) con Apache y MySQL/MariaDB activos.
  • Instale PHP 8.1+ y Composer y asegúrese de que php y composer estén en el PATH.
  • Clone o copie el proyecto en htdocs/ITSI (o la ruta que use su servidor).
  • En la raíz del proyecto ejecute composer install para generar vendor/.
  • Ajuste app/Config/App.php → $baseURL a la URL real (p. ej. http://localhost/ITSI/public/).
  • Configure credenciales de base de datos en app/Config/Database.php o mediante archivo .env según convención CI4.
  • Para recuperación de contraseña, complete SMTP en app/Config/Email.php o variables de entorno documentadas en ese archivo.
  • Si usa la barra de depuración de CI4, los artefactos se escriben en writable/debugbar/.

6. Instalación del sistema (resumen técnico)

La instalación consiste en disponer del código, instalar dependencias PHP, importar el esquema SQL y alinear la configuración (baseURL, BD, correo). El detalle paso a paso se amplía en la Parte II — Guía de instalación.

7. Configuración de la base de datos

El archivo bddITSI.sql crea la base itsi y todas las tablas (prefijo conceptual TAB_). Incluye comentarios sobre importación: si una herramienta gráfica falla por comprobación de claves foráneas, importe por línea de comandos o desactive temporalmente esa opción.

En aplicación, el grupo por defecto está en app/Config/Database.php (database = 'itsi', driver MySQLi, puerto 3306). La collation en configuración puede ser utf8mb4_general_ci; el script usa utf8mb4_unicode_ci a nivel de BD — mantener UTF-8 de extremo a extremo.

Ejemplo de importación por consola (ajuste usuario y ruta):

mysql -u root -p < "c:\xampp\htdocs\ITSI\bddITSI.sql"

8. Procedimiento de despliegue del sistema

  1. Servidor: PHP 8.1+, extensiones habituales (mysqli, mbstring, openssl, json, intl según necesidad), Apache o Nginx.
  2. Document root: en producción se recomienda apuntar el virtual host únicamente a public/, no a la raíz del proyecto.
  3. Archivos: subir el código (sin writable/debugbar innecesario en producción si se desea); ejecutar composer install --no-dev --optimize-autoloader en el servidor.
  4. Permisos: el usuario del servidor web debe poder escribir en writable/ y en rutas de subida de archivos definidas en los controladores de documentos.
  5. Configuración: establecer baseURL con HTTPS en producción; desactivar o ajustar DBDebug y toolbar de depuración.
  6. Base de datos: restaurar desde bddITSI.sql o desde backup coordinado (BackupCoordController si está en uso).
  7. Correo: configurar SMTP real para notificaciones y recuperación de contraseña.
  8. Seguridad: revisar filtros en app/Config/Filters.php (p. ej. forcehttps en entornos con TLS terminado en proxy).
Revise si en su entorno local el filtro global forcehttps provoca redirecciones no deseadas sin HTTPS; en ese caso ajuste la configuración solo para el entorno correspondiente.

Parte II — Guía de instalación y ejecución

Esta guía permite a una persona con conocimientos básicos de Windows y XAMPP instalar y ejecutar ITSI en un equipo de desarrollo. Está integrada en el mismo documento que el manual técnico; puede extraerse como anexo si lo necesita su institución.

1. Requisitos del sistema y herramientas necesarias

Sistema operativoWindows 10/11 (esta guía), Linux/macOS equivalente con Apache+Nginx+PHP+MySQL
RAMMínimo 4 GB recomendado para XAMPP + navegador + MySQL
XAMPPCon Apache y MySQL/MariaDB
PHP8.1 o superior (incluido en XAMPP reciente)
Composergetcomposer.org

OpcionalphpMyAdmin (incluido en XAMPP) para importar SQL

2. Instalación de dependencias

  1. Abra una terminal en la carpeta raíz del proyecto (ITSI).
  2. Ejecute: 
    composer install
  3. Verifique que exista la carpeta vendor/ y que no haya errores de extensión PHP faltante.

3. Configuración del proyecto

  1. Edite app/Config/App.php y asigne public string $baseURL a la URL desde la que accederá, por ejemplo: 
    public string $baseURL = 'http://localhost/ITSI/public/';
  2. Edite app/Config/Database.php (o use .env) con usuario, contraseña y nombre de base itsi.
  3. Para correo, siga los comentarios de app/Config/Email.php (SMTP recomendado en Windows).
  4. Imagen de fondo del login: archivo referenciado en app/Config/Auth.php (loginBackgroundImage), relativo a public/.

4. Creación de la base de datos

  1. Inicie MySQL desde el panel de control de XAMPP.
  2. Importe el archivo completo bddITSI.sql (desde phpMyAdmin: Importar, o desde consola como en la sección 7).
  3. Confirme que la base itsi existe y contiene tablas TAB_USUARIOS, TAB_ESTUDIANTES, etc.

5. Ejecución del sistema

  1. Inicie Apache en XAMPP.
  2. Abra el navegador en la URL configurada en baseURL, por ejemplo: 
    http://localhost/ITSI/public/
  3. Debe mostrarse la pantalla de inicio de sesión. Use las credenciales que existan en su base (datos semilla del script SQL o usuarios creados posteriormente).
  4. Si aparece error 500, revise writable/logs/ y permisos de escritura en writable/.
